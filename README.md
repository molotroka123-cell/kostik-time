# Kostik Time

Точный статический трекер договорной неустойки для личного использования.

- основной долг: **€5 000**
- начало просрочки: **01.08.2026**
- договорная неустойка: **€50 за каждый начатый день**
- расчёт ведётся по календарной дате **Europe/Prague**
- таймер показывает время до следующего начисления `+€50`
- таблица автоматически строит историю начислений по дням
- сумма обновляется на клиенте без сервера и без ручных правок

## Проверка контрольных дат

- 31.07.2026 → 0 дней → €0 неустойки → €5 000 всего
- 01.08.2026 → 1 день → €50 неустойки → €5 050 всего
- 08.09.2026 → 39 дней → €1 950 неустойки → €6 950 всего
- 09.09.2026 → 40 дней → €2 000 неустойки → €7 000 всего

## Важно

Это расчётный интерфейс, а не юридическое заключение. В итог не включены законные проценты, судебные расходы, расходы на адвоката и возможная судебная корректировка договорной неустойки.
